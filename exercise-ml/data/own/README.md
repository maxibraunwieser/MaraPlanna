# Eigene Aufnahmen

Hier landen die Aufnahmen des Recorders (Phase 1). Das Format wird mit dem Recorder festgelegt und hier dokumentiert.
Geplant ist eine Zeile pro Satz: Person, Handgelenk (L/R), Übung, Wiederholungen, Abtastrate und die Rohdaten (Beschleunigung in milli-g, Gyroskop in Grad/s).
Nichts davon gehört in Git (siehe `.gitignore`).
